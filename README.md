# Chemistry Corner Malta

Official website for **Chemistry Corner Malta**, an O Level chemistry tuition and learning-resource service based in Malta.

## Current website

The first version introduces:

- Year 9, Year 10 and Year 11 chemistry tuition
- From Scratch support
- Exam preparation
- Upcoming student learning resources
- Francesco Galea's teaching approach

The website is built as a lightweight static site using HTML, CSS and JavaScript, ready for GitHub Pages.

## Privacy

No student names, schedules, payment information or private teaching records should be committed to this public repository.
